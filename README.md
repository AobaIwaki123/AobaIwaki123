# AobaIwaki123

AI・インフラ・OSSを横断して、個人開発とホームラボ運用をしています。

イベント情報を集めて使える形にしたり、AIを使ったプロダクトを作ったり、Kubernetes基盤を自分で運用したりしています。実装だけでなく、収集・変換・表示・運用まで一通りつなげることを大切にしています。
